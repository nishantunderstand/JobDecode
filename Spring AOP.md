AOP vs Interceptor 
  
AOP is a higher-level programming model for separating and applying cross-cutting concerns using concepts such as aspects, pointcuts, and advice. 

An interceptor is a lower-level mechanism that intercepts a method invocation and can execute logic before, after, or around it. 

In Spring, AOP is commonly implemented using proxy-based interception.
