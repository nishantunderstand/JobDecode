Job description
We are looking for a motivated and experienced Java Developer with 4-6 years of hands-on experience in designing, developing, and deploying enterprise-grade applications. The ideal candidate should have strong expertise in Java and Microservices , experience with AWS cloud technologies , and exposure to CI/CD pipelines and Kubernetes . The candidate will play a key role in developing scalable, cloud-native applications and driving automation across the software delivery lifecycle.


Key Responsibilities


Java Development

Design, develop, test, and maintain scalable Java-based applications.
Build and enhance microservices using Java, Spring Boot, and RESTful APIs.
Develop high-quality, reusable, and maintainable code following best practices.
Participate in application architecture, design reviews, and technical discussions.
Troubleshoot application issues and perform root cause analysis.
Optimize application performance, scalability, and reliability.
Collaborate with product owners, architects, QA teams, and other stakeholders.
AWS Cloud

Deploy and manage applications on AWS cloud environments.
Utilize AWS services such as EC2, S3, RDS, Lambda, ECS/EKS, IAM, and CloudWatch.
Support cloud-native application development and migration initiatives.
Monitor, troubleshoot, and optimize cloud-based solutions.
Implement security and compliance best practices within AWS environments.
CI/CD & Kubernetes

Design and maintain CI/CD pipelines using Jenkins, GitHub Actions, GitLab CI/CD, or similar tools.
Containerize applications using Docker and deploy them on Kubernetes platforms.
Monitor and manage Kubernetes workloads, deployments, and services.
Automate build, testing, deployment, and release processes.
Work closely with DevOps teams to improve deployment efficiency and reliability.
